## What to Adjust

If you're running long:
- [ ] Cut the least essential finding
- [ ] Reduce detail in the methodology section
- [ ] Streamline transitions between slides

If you're running short:
- [ ] Add examples or stories
- [ ] Expand on implications
- [ ] Allow more time for questions

## Practice Protocol

| Run | Focus |
|---|---|
| 1 | Just get through it (don't stop, even if you stumble) |
| 2 | Timing (note which slides run long/short) |
| 3 | Transitions (smooth connections between slides) |
| 4 | Record and review |
| 5 | Final polish (fix issues from the recording) |

Watch for: filler words (um, uh, like), rushing key points, reading slides, lack of eye contact,
monotone delivery, unclear chart explanations.
