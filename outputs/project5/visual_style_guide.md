# Presentation Visual Style Guide

## Color Palette

| Use | Color | Hex Code |
|---|---|---|
| Primary data | Dark Blue-Gray | #2C3E50 |
| Recommended sponsor / highlight | Orange | #F39C12 |
| Positive indicators | Green | #27AE60 |
| Negative indicators | Dark Red | #C0392B |
| Neutral / context | Gray | #95A5A6 |
| Background | White | #FFFFFF |

Limit each chart to three colors maximum. Use the primary for most elements and the orange only to
highlight the recommended option.

## Chart Formatting

- **Dimensions**: 12" x 6.75" (16:9 aspect ratio)
- **DPI**: 200 for sharp rendering
- **Font**: Arial or Helvetica (DejaVu Sans in generated charts)
- **Border**: none (clean edges)

## Typography

| Element | Size | Weight |
|---|---|---|
| Slide title | 28-36pt | Bold |
| Body text | 18-24pt | Regular |
| Chart title | 20pt | Bold |
| Data labels | 12-14pt | Bold |

- Maximum 3-5 bullets per slide; maximum 10-12 words per bullet.
- At least 20% of every slide should be white space.

## Data Labels

- Place values ON the chart, not in a separate legend.
- Round to whole numbers unless precision matters.

## Charts NOT to use

- Pie charts (hard to compare)
- 3D charts (distort data)
- Dual-axis charts (confusing)
- Charts with more than about six data points (overwhelming)
